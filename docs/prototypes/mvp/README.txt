==================================
更新日期：2026-10-13

入口：解壓後開啟 index.html，從「建置指引 → 增量規則與交接」閱讀本次變更。

本次增量：
1. 自由試驗場：同名匹配 / 腳本預設 / 人工指定 / 參數連線。
2. 支援直接上游、跨欄位綁定、重複節點的最後成功出參、型別保留。
3. 執行前全圖驗參，執行時驗證實際入參；固定腳本、契約與綁定快照。
4. 報告增加參數來源、節點 ID、重複次數、實際入參與成功出參。
5. 等高三區工作台、固定 250 px 參數區、200 px 緊湊節點、可點選連線。
6. 儲存失敗保留草稿、重設覆蓋值、移除連線清理引用、畫布適應不改座標。
7. Python 真實範例與行為回歸，可重現「建立兩次 → 查詢最後一次」。

保留的功能：
- 場景卡片、穩定編號、腳本入口、入參 / 出參設定與預設調試網址。
- 錄製草稿 → 調試與標準化 → 驗證 → 確認發布的生命週期。
- 自主交付報告多選篩選、腳本快照與版本失效規則。
- 頂部第一級、左側第二級 Portal；既有配色、字體及高資訊密度。

三個交付層次：
- HTML：可操作的離線原型，結果標示為模擬。HTML 不啟動瀏覽器或 AI。
- python-demo：真正操作本機目標頁的 Python / Playwright 範例。
- 建置指引：管理 API、AI 調試、登入憑證與瀏覽器串流仍需新工程實作。

BA-001：建立範例紀錄；BA-002：查詢並核對紀錄編號、數量及可選標題。
內容均為中性示範，沒有外部帳號、憑證或原工程業務資料。
portal.css / shell.js 與原視覺風格交付物保持一致；新增樣式僅作用於試驗場。
舊 v1 原型的瀏覽器儲存資料不刪除；新版使用獨立 v2 儲存區。

可直接使用：
- sample-run/index.html：本次真實執行報告與三次瀏覽器截圖。
- contracts/：入出參 Schema、預設值、場景契約與工作流範例。
- python-demo/README.txt：安裝、真實執行與回歸命令。
- 驗證紀錄.txt：覆蓋範圍與限制。
- MANIFEST.json：逐檔 SHA-256（清單不包含自身）。

將整包提供給新工程，以 HTML 指引拆分建置任務，不應將模擬結果當作真實驗證。
