瀏覽器自動化 MVP · 繁體中文 · v1.0
==================================

1. 先開啟 index.html（離線互動原型，無須安裝）。
2. 場景管理：查看腳本、入參／出參、保存調試網址、模擬執行。
3. 場景生產：錄製草稿生命週期、報告篩選、自由試驗場序列編排。
4. 建置指引：模組分工、資料／API 契約、驗收及新工程任務書。
5. 真實瀏覽器功能：按 python-demo/README.txt 安裝後執行。

請注意三種層次：
- index.html：HTML 原型，結果一律標示模擬，不啟動瀏覽器或 AI。
- python-demo：真正操作本機頁面的 Python / Playwright 最小鏈路。
- 建置指引：管理 API、助手、登入憑證與遠端瀏覽器串流為新工程待實作能力。

BA-001：建立範例紀錄；BA-002：使用前一場景出參查詢紀錄。
兩個場景均無外部帳號、憑證或原工程業務資料。
HTML 與視覺風格包共用完全相同的 portal.css / shell.js。

建議先把這個壓縮包提供給新工程，從 index.html → 建置指引開始。

附帶 sample-run/index.html：本次已通過的真實本機範例報告與截圖。
contracts/：可直接複用的 Schema 與預設值。
