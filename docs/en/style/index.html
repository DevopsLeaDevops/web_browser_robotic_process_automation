Rules to follow

  • Compact information density. No large banners, illustrations or lots of white space; keep repeated headings only once.
  • States need words. Never rely on an icon or colored dot alone.
  • Keyboard accessible. Clear focus outlines; dialogs close with Esc.
  • Accepted at three sizes. 1440×900, 1280×720, 390×844, with no horizontal scrolling of the whole page.
  • No extra navigation. New pages always go into the two-level portal.

To confirm with the designer in M6

Gaps found while including the package
  • Incomplete design tokens. tokens.json has no success, warning, error or selected-background colors; they appear only in portal.css.
  • Inconsistent selected background. The design system's color page says #eaf3ff, while portal.css actually uses #eaf4ff.
  • Step editor details. Flow canvas and node styles exist, but there are no states for dragging, switching locator candidates or marking validation errors.
  • Run details. The layout for step-by-step logs, screenshot replay and trace links.
  • YAML editor. Basic code-editor styles exist; syntax highlighting and error-line marking need confirming.
  • Icons. There is only one generic icon so far; menus and actions need a set.
  • Dark mode. Not available yet; confirm whether it is needed.
  • Layouts in three languages. The design package was designed in Traditional Chinese; English is usually longer, so check the prototypes once in English and once in Simplified Chinese; see ADR 0007.
