Why this order

  • CLI before UI. Every capability can be verified without an interface; the web UI is a layer on top.
  • Generation before the management backend. Generation is what sets this project apart. Until M6, scenarios live as YAML files in the repository and Git is the version control.
  • Prototypes before the backend. The M6 page prototypes decide what data the M7 API must provide.
  • The runner is stateless from day one. It takes scenarios, parameters and secrets and outputs results and artifacts, so in M9 it goes straight into the workers.
