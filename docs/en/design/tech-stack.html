Version baseline

Set in M0
Python
3.12 or later (CI tests 3.12 and 3.13; 3.13 by default locally, see .python-version)
uv
0.11 or later (required-version in pyproject.toml)
Type checking
pyright in strict mode; all new code is fully annotated
Dependency locking
uv.lock records the exact version of every package and is committed to the repository; CI installs with uv sync --locked and fails when the lock file and pyproject.toml disagree
Dependency updates
Dependabot checks GitHub Actions and Python dependencies weekly
