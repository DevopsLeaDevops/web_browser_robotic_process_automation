In one sentence

The core asset is the scenario: a repeatable sequence of browser actions described in a declarative DSL. The platform generates scenarios (recording, natural language, templates), manages them (versions, parameters, permissions), runs them (Playwright), and reports results back to users (screenshots, traces, failure location).

Repository status

M10 in progress
rpa-core
Models of the scenario DSL and the scenario contract, YAML loading and validation, converting recordings into DSL drafts; examples in scenarios/
rpa-runner
Execution engine: input validation, login checks, running the steps in Chromium or Firefox, independent assertions, output publishing, run reports; subprocesses for manual login and step debugging
rpa-worker
Background worker: claims jobs, runs them in a subprocess, cancels them; no database dependency. It can also run on another computer as a remote worker, claiming jobs through the portal's Worker API (M9a)
rpa-server
Management portal: FastAPI API and Jinja pages, SQLite, revisions and the publishing gate, the run queue, login roles and secrets, recording, step debugging, the playground, remote worker registration and dispatch
rpa-cli
rpa serve starts the management portal (--worker-port opens it to remote workers); rpa worker turns another computer into a remote worker; rpa run runs a scenario; rpa record records actions and turns them into a scenario draft; rpa validate checks scenarios and points to the line, step and field, rpa schema prints the JSON Schema of the DSL or of one scenario's inputs and outputs; --lang switches between Traditional Chinese, Simplified Chinese and English
Toolchain
uv (dependencies locked in uv.lock), ruff, pyright (strict), pytest, pre-commit
CI
Static checks; all tests on Python 3.13 (including real-browser tests in Chromium and Firefox, in 4 parallel processes), and on Python 3.12 only the tests that need no browser for PRs, all tests on pushes to main; the setup scripts run on macOS, Ubuntu and Windows when the scripts or dependencies change, and weekly; every night all tests run on the three systems, with the browser tests repeated three times
Docs
This site, in Traditional Chinese, Simplified Chinese and English, with automatic checks for links and translation sync
