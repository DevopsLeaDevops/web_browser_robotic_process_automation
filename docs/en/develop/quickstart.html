Run locally from scratch

One command takes a computer with no development tools to a working CLI, passing tests and a readable docs site. Works on macOS, Linux and Windows; the first run takes about ten minutes, mostly downloading.

"Working" means: the rpa command runs (it currently has rpa validate and rpa schema), all tests pass, Playwright can start Chromium and Firefox, and the docs site opens in a browser. Running and recording scenarios arrive in later milestones; see the Roadmap.

macOS, Linux

Run in Terminal
# No code yet: download to ~/code/web_browser_robotic_process_automation and install
curl -LsSf https://raw.githubusercontent.com/DevopsLeaDevops/web_browser_robotic_process_automation/main/scripts/setup.sh | bash

# Already cloned: run inside the project folder
./scripts/setup.sh

Windows

Run in PowerShell
# No code yet: download the script, then run it; the code goes to %USERPROFILE%\code\web_browser_robotic_process_automation
irm https://raw.githubusercontent.com/DevopsLeaDevops/web_browser_robotic_process_automation/main/scripts/setup.ps1 -OutFile $env:TEMP\rpa-setup.ps1
powershell -ExecutionPolicy Bypass -File $env:TEMP\rpa-setup.ps1

# Already cloned: run inside the project folder
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1

What you need first

macOS
Nothing. Without Git, the script opens the installer for the Command Line Developer Tools; when it finishes, run the same command again.
Linux
Git, plus curl or wget. If the browsers are missing system libraries, the script installs them with sudo (Debian and Ubuntu only).
Windows
Windows 10 or later; the built-in PowerShell 5.1 is enough. Without Git, the script installs it with winget.
Network
Access to GitHub, astral.sh (uv), PyPI and Playwright's browser downloads. On a company network, see the FAQ.
Disk space
About 1.5 GB for Python, packages, Chromium and Firefox.
Not needed
You do not install Python, Homebrew or Node.js yourself. uv downloads Python and leaves the system Python alone.

Reading the script before running it

  • The scripts are scripts/setup.sh and scripts/setup.ps1 in the repository, with full usage notes at the top.
  • If you prefer to read first: open the URL from the command in a browser, or git clone first and run the copy in the project. The Windows command already saves the script as a file, so you can read it before running the second line.
  • The script only installs uv and Python in your home folder, creates .venv in the project folder and downloads Chromium and Firefox. The only steps that need system permissions are installing Git (macOS, Windows) and Linux browser libraries, and both ask first.
  • Running it again is safe: finished steps are skipped quickly, so after fixing a problem just rerun the same command.

What the script does

The same steps on every platform
StepWhat it doesWhen already done
1. Check the systemConfirms the operating system and CPU architecture. Warns when an Apple silicon Mac is running under Rosetta.Checked every time
2. Prepare the codeUses the project it runs in; otherwise git clones to the default location or the one given with --dir.Uses the existing download; does not git pull automatically
3. Prepare uvInstalls it with the official installer if missing; tries to upgrade when older than required-version in pyproject.toml.Skipped when new enough
4. Install Python and dependenciesuv sync: prepares Python 3.13 per .python-version, creates .venv, installs all packages and dev tools at the versions in uv.lock.Finishes in seconds when nothing changed
5. Install the browsersuv run playwright install chromium firefox, then actually starts them once. On Linux, runs playwright install-deps if system libraries are missing.Skips the download and only checks that it starts
6. Install pre-commit checksuv run pre-commit install, so ruff, pyright and the docs checks run before every git commit.Rewrites the same hook, no effect
7. Confirm it worksRuns rpa --version, then all tests with RPA_REQUIRE_BROWSER=1: like CI, a missing browser fails instead of being skipped.Runs every time

The from-scratch commands accept options too:

# macOS, Linux: put options after bash -s --
curl -LsSf https://raw.githubusercontent.com/DevopsLeaDevops/web_browser_robotic_process_automation/main/scripts/setup.sh | bash -s -- --skip-browser

# Windows: put options after the script path given to -File
powershell -ExecutionPolicy Bypass -File $env:TEMP\rpa-setup.ps1 -SkipBrowser

What success looks like

The last step prints the version and all tests report only passed, followed by "完成" (done) and the commands you can use next. The setup scripts print their messages in Traditional Chinese:

[7/7] 確認能運行
  ✓ rpa 0.1.0（rpa-core 0.1.0）
  $ env RPA_REQUIRE_BROWSER=1 uv run pytest
…
============================= 46 passed in 2.91s ==============================
  ✓ 全部測試通過

完成！本機環境已經可以運行。

接下來在專案資料夾裡：
  cd /Users/you/code/web_browser_robotic_process_automation
  uv run rpa -h                               # 命令列工具
  uv run pytest                               # 跑測試
  open docs/index.html                        # 開啟文檔站
  uv run python -m http.server -d docs 8000   # 或用本機伺服器瀏覽文檔
  • The number of tests grows with the code and docs pages; what matters is no failed and no skipped.
  • If something fails, the script marks where it stopped and how to fix it with ✗ ([X] on Windows).
  • Lines starting with ! ([!] on Windows) are warnings: they do not stop anything, but are worth reading.
  • rpa itself prints Traditional Chinese by default; add --lang en, or set RPA_LANG=en, for English.

Every time after that

cd ~/code/web_browser_robotic_process_automation
git pull              # get the latest code
./scripts/setup.sh    # installs only what changed in dependencies or browsers, then reruns the tests; scripts\setup.ps1 on Windows

To update dependencies without the full run, uv sync is enough. Other common commands are in Dev environment.

FAQ

What you seeWhat to do
Windows: "running scripts is disabled on this system"Use the commands on this page with -ExecutionPolicy Bypass; it applies to that run only, with no system setting changed.
Windows: running with irm … | iex reports "is not recognized" or "Unexpected attribute"Use this page's two commands that download first and then run with -File. The script is saved as UTF-8 with a BOM so Windows PowerShell 5.1 reads its Chinese text correctly, but the BOM stays in the string irm downloads and makes iex fail to parse it.
macOS: "請在跳出的視窗按『安裝』" (click Install in the pop-up window)Install the Command Line Developer Tools, then run the same command again. You do not need the full Xcode.
"已經存在，而且不是空資料夾" (already exists and is not empty)Something else occupies the default location. Pick another one with --dir (-Dir on Windows); if it is the project, go into the folder and run scripts/setup.sh.
"安裝依賴失敗" or "下載瀏覽器失敗" (installing dependencies / downloading the browsers failed)Usually the company network. Set UV_INDEX_URL or PLAYWRIGHT_DOWNLOAD_HOST and rerun, see the Dev environment FAQ; if the browser cannot be downloaded for now, add --skip-browser.
Linux: "瀏覽器缺少系統函式庫" (the browsers are missing system libraries)The script runs playwright install-deps with sudo and asks for your password. On distributions other than Debian and Ubuntu, install the missing libraries by hand as the error describes.
uv is not found after the script finishesThe script just installed uv, which only takes effect in new terminal windows. Open a new window; on macOS and Linux you can also run source $HOME/.local/bin/env.
"測試沒有通過" (tests did not pass)Scroll up to find the FAILED test names and errors. Running uv run pytest -x in the project folder stops at the first failure.
Start over completelyDelete .venv in the project and run the script again. For Mac-specific issues (Rosetta, xcrun: error and so on) see the Run on macOS FAQ.
If you would rather not use the script, or want the details of every step: the Mac walkthrough is in Run on macOS, and the commands common to all platforms are in Dev environment.
