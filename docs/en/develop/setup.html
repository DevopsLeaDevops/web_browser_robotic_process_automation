Dev environment

From nothing to running tests in about five minutes. The commands are the same on Windows, macOS and Linux. To set up everything with one command, use the setup script in Run locally from scratch; for a first setup on a Mac, follow Run on macOS step by step.

First-time setup

git clone https://github.com/DevopsLeaDevops/web_browser_robotic_process_automation.git
cd web_browser_robotic_process_automation

# Create .venv and install all packages and dev tools
uv sync

# Download Chromium and Firefox (on Linux, add --with-deps the first time to install system dependencies)
uv run playwright install chromium firefox

# Automatic checks before each commit
uv run pre-commit install

# Confirm the installation
uv run rpa --version

Prerequisites

Python
3.12 or later. uv downloads it if missing.
uv
0.11 or later; see the official uv docs for installation.
Git
Any recent version.
Node.js
Only needed once frontend work starts in M8.
Database
Nothing to install. From M7, development uses SQLite (built into Python); PostgreSQL is only needed in production. See ADR 0008.

FAQ

CI says uv.lock needs updating
A dependency in pyproject.toml changed without updating the lock file. Run uv lock and commit uv.lock together with the change.
PyPI unreachable from the intranet
Set the UV_INDEX_URL environment variable to the company's package mirror.
Browser download fails
Set PLAYWRIGHT_DOWNLOAD_HOST to an internal mirror; the browser smoke test is skipped automatically when no browser is installed locally.
Tests say Simplified Chinese is not up to date
After changing Traditional Chinese docs or message catalogs, run uv run python tools/i18n.py sync and commit the generated files.
Tests say the English translation needs updating
Update the same page under docs/en/ to match the Traditional Chinese change, then run the stamp command shown in the test message.
pyright cannot find packages
Make sure you have run uv sync and your editor uses the project's .venv.
