必守规则

  • 紧凑信息密度。不用大横幅、插画或大量留白；重复的标题只保留一次。
  • 状态要有文字。不能只用图标或色点。
  • 键盘可操作。焦点框清楚；对话框可用 Esc 关闭。
  • 三种尺寸验收。1440×900、1280×720、390×844，不得出现整页水平卷动。
  • 不另造导览。新页面一律放进两级 Portal。

收录时发现的缺口
  • 设计变量不完整。tokens.json 没有成功、警告、错误与选取背景色；这些只出现在 portal.css。
  • 选取背景色不一致。设计系统的色彩页写 #eaf3ff，portal.css 实际使用 #eaf4ff。
  • 步骤编辑器细节。已有流程画布与节点样式，但没有拖拽、定位器候选切换、校验错误标示的状态。
  • 运行详情。逐步日志、截图回放与 Trace 链接的版面。
  • YAML 编辑器。已有 code-editor 基础样式，需确认语法高亮与错误行标示。
  • 图标。目前只有一个通用图标，菜单与动作需要一套图标。
  • 深色模式。目前没有，需确认是否需要。
  • 三种语言的版面。设计包以繁中设计；英文通常较长，原型要用英文与简中各检查一次，见 ADR 0007。
