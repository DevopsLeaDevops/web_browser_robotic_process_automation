版本基准

M0 设置
Python
3.12 以上（CI 测 3.12 与 3.13；本机默认 3.13，见 .python-version）
uv
0.11 以上（pyproject.toml 的 required-version）
类型检查
pyright strict 模式，新代码一律完整标注类型
依赖锁定
uv.lock 记录每个包的确切版本并提交到仓库；CI 以 uv sync --locked 安装，锁文件与 pyproject.toml 不一致时失败
依赖更新
Dependabot 每周检查 GitHub Actions 与 Python 依赖
