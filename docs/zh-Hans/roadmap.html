为什么是这个顺序

  • CLI 先于 UI。每个能力都能在没有界面的情况下验证，Web UI 只是在上面加一层。
  • 生成先于管理后端。生成是本工程的核心差异；M6 之前场景以 YAML 文件放在仓库，Git 就是版本控制。
  • 原型先于后端。M6 的页面原型决定 M7 的 API 需要提供哪些数据。
  • Runner 从一开始就无状态。只吃场景、参数与 Secrets，输出结果与产物，到 M9 直接放进 worker。
