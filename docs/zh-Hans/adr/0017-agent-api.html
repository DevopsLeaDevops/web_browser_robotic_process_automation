ADR 0017：第三方 Agent 经由独立、以 API 密钥授权的 /agent-api/v1 操作平台

Agent 只连服务器；调试交给指定的录制端，验证与运行交给 Worker，业务规则与发布门槛沿用现有服务。新的一层只做认证、权限、审核与对外契约。

已接受
日期
2026-10-23
影响范围
rpa-server（新路由、API 用户端、审核、迁移）、rpa-runner（调试的 snapshot 命令）、RPA 录制端 App（读页面结构）；第二期另含 rpa-worker
相关
ADR 0011（API 与 OpenAPI）、ADR 0012（Worker API）、ADR 0014（录制端与交互子进程）、ADR 0015（版本与发布记录）；设计：对外 Agent API；Agent 使用指南

背景

用户要求（2026-10-23）：第三方的 Agent 系统使用 Linux 服务器的 API 操作录制端，完成场景脚本与参数的添加、修改、调试运行；再经由服务器调用 Worker 完成验证与运行，并取得运行过程。

现有的 /api 已有场景、版本、调试、验证、运行的全部操作，但没有认证：只开在服务器本机的 8080，或带录制端的设备权杖从对外端口进来。交互子进程开在「请求经过的那台录制端」，Agent 不经过录制端，无法指定。Worker 只回报五个阶段，没有步骤级的进度。

决策

  1. 独立的对外 API。对外端口添加 /agent-api/v1，有自己的 OpenAPI；路由只转接服务层，不拷贝业务规则。/api、Client API、Worker API 不变。
  2. API 用户端。每个 Agent 系统在管理后台登记为一个用户端，密钥只显示一次、只存哈希。用户端设置权限范围（scenes:read、scenes:write、debug、runs:validate、scenes:publish、runs:execute、runs:read）、可用领域与录制端、运行位置与 Worker、限额、回传页面内容、到期与来源 IP。
  3. Agent 只连服务器。调试请求带 recorderId，服务器以现有的 use_recorder 把子进程交给那台；录制端要在设备页打开「允许 Agent 调试」，可以只允许无头。场景已有人在调试时回 409，不关掉对方。
  4. 发布要个别授权。Agent 可以发布，但只有勾选 scenes:publish 的用户端可以，默认不勾（用户 2026-10-23 决定）。发布门槛不变：发布的版本必须是验证通过、哈希相符的版本。
  5. 页面内容默认不回传。截图、页面结构与录像受用户端的「回传页面内容」控制，默认关；管理员确认 Agent 的模型可以接收内部页面后再打开（用户同意的建议）。Secrets 的值永远不回传。
  6. 读页面结构在第一期。调试子进程加 snapshot 命令（无障碍树、表单字段、iframe 与标签页），值遮罩；录制端上线时回报支持，旧版回 409 并提示更新（用户 2026-10-23 要求提前）。
  7. 运行过程。第一期提供状态、阶段、结束后的步骤与产物；第二期由 steps.json 经心跳回报步骤进度，提供事件长轮询与 Webhook。
  8. 审核。每个写入请求记下时间、用户端、动作、对象与结果，只增不改；版本与运行标出触发的用户端。
  9. 不做 MCP 转接。只提供 HTTP API 与使用指南（用户 2026-10-23 决定）。

后果

  • 大部分端点是转接，第一期的工作集中在认证、权限、审核、指定录制端与读页面结构。
  • 多一个对外的界面：密钥在 HTTP 下是明文。Agent 系统与服务器在同一个局域网（用户 2026-10-23 确认），第一期不要求 HTTPS；Agent 移到局域网外时要在服务器前加 HTTPS。
  • 读页面结构要出新版录制端 App；旧版 App 仍可调试，只是不能读页面结构。
  • Agent 接外部模型时，打开「回传页面内容」等于让内部页面离开内网；这要由管理员逐个用户端决定。
  • M8 加入用户与项目权限时，API 用户端要并入同一套权限模型。

没有选的方案

方案为什么不选
直接对外开放 /api 并加权杖/api 跟着 Portal 界面改动，不适合当对外契约；权限与审核要穿插在每个页面用的路由里。
Agent 直接连录制端或 Worker录制端与 Worker 要开端口、Agent 要知道每台的位置；破坏「所有连接由 App 主动发起」（ADR 0012、0014）。
在服务器开浏览器给 Agent 调试Linux 服务器没有画面也可能没装浏览器；录制、调试的浏览器开在录制端（ADR 0014）。
远程画面实时传输ADR 0014 已决定不做；Agent 用截图与页面结构即可。
一开始就用 SSE 或 WebSocket 推送事件长轮询与 Worker、录制端一致，穿得过代理；推送等第二期再评估。
MCP 转接用户 2026-10-23 决定不做。
