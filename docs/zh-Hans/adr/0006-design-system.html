ADR 0006：采用界面设计系统 v1.0 作为视觉契约

同事交付的设计包原样收录，文档站与未来的 Web UI 共用。

已接受
日期
2026-10-09
影响范围
docs/、M6 页面原型、M8 Web UI
相关
风格总览、ADR 0004

背景

路线图的 M6 是网站风格设计。同事已交付一版界面设计系统 v1.0：设计变量、共用样式、两级菜单外壳与起始版型，并在三种屏幕尺寸验证过。

决策

  • 设计包原样收录在 docs/design-system/，不直接修改；MANIFEST.json 的 sha256 由测试检查。
  • 文档站从 M0 起使用它的 portal.css。
  • M6 以 starter.html 为基础制作本工程的页面原型。
  • M3 起管理界面的 Jinja 页面直接使用 portal.css 与 tokens.json（原计划 M8 移植到 React，已由 ADR 0011 改变）。
  • 设计包更新时整包替换，并在本页记录版本。

后果

好处

  • 文档与产品风格一致；M6 从「设计风格」缩小为「设计页面」。
  • 设计包已包含流程编辑器相关样式（流程画布、节点、组件库），可直接用于步骤编辑器。

代价

  • 本工程需要但设计包尚未涵盖的部分，要在 M6 与设计者确认，见风格总览。
  • 不能直接改设计包；本工程的补充样式写在自己的文件里。

没有选的方案

方案为什么不选
重新设计重复工作，且已有验证过的成果。
采用现成组件库需要另外调整成团队风格，与设计包重叠。
