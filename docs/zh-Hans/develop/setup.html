开发环境

从零到能跑测试，大约五分钟。Windows、macOS、Linux 指令相同。想一条命令装好全部，用本机从零运行的一键脚本；第一次在 Mac 上设置，可照macOS 本机运行一步步做。

第一次设置

git clone https://github.com/DevopsLeaDevops/web_browser_robotic_process_automation.git
cd web_browser_robotic_process_automation

# 创建 .venv，安装全部包与开发工具
uv sync

# 下载 Chromium（Linux 第一次可加 --with-deps 安装系统依赖）
uv run playwright install chromium

# 提交前自动检查
uv run pre-commit install

# 确认安装成功
uv run rpa --version

前置需求

Python
3.12 以上。没有的话 uv 会自动下载。
uv
0.11 以上，安装方式见 uv 官方文档。
Git
任一近期版本。
Node.js
M8 开始做前端时才需要。
数据库
不用安装。M7 起开发用 SQLite（Python 内置）；PostgreSQL 只有正式环境需要，见 ADR 0008。

常用命令

做什么命令
安装或检查整个环境./scripts/setup.sh（Windows：scripts\setup.ps1），见本机从零运行
跑全部测试uv run pytest
跳过需要浏览器的测试uv run pytest -m "not browser"
只检查文档uv run pytest tests/docs
Lint 并自动修正uv run ruff check --fix .
格式化uv run ruff format .
类型检查uv run pyright
提交前的全部检查uv run pre-commit run --all-files
替某个包加依赖uv add --package rpa-core 包名称（会一并更新 uv.lock，两个文件一起提交）
以其他语言显示 rpauv run rpa --lang en -h，或设置环境变量 RPA_LANG=zh-Hans
重新产生简中、检查翻译uv run python tools/i18n.py sync、uv run python tools/i18n.py check，见三种语言
浏览文档直接打开 docs/index.html，或 python -m http.server -d docs 8000

常见问题

CI 说 uv.lock 需要更新
改了 pyproject.toml 的依赖却没有更新锁文件。运行 uv lock，把 uv.lock 一起提交。
内网连不到 PyPI
设置环境变量 UV_INDEX_URL 指向公司的包镜像。
浏览器下载失败
设置 PLAYWRIGHT_DOWNLOAD_HOST 指向内部镜像；浏览器冒烟测试在本机没有浏览器时会自动略过。
测试说简中不是最新
改了繁中文档或消息目录后，运行 uv run python tools/i18n.py sync 并提交产生的文件。
测试说英文翻译需要更新
依繁中的修改更新 docs/en/ 的同一页，再运行测试消息里的 stamp 命令。
pyright 找不到包
确认已运行 uv sync，且编辑器使用的是项目的 .venv。
