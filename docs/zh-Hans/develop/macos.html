macOS 本机运行

在一台没装过开发工具的 Mac 上，从下载代码到跑通 CLI、测试与文档站的逐步说明。第一次大约十分钟，多半在等下载。想一条命令自动做完下面的步骤，用本机从零运行的一键脚本。

目前是 M0（工程骨架）。「能运行」指的是：rpa 命令可以运行、全部测试通过、Playwright 能启动 Chromium、文档站能在浏览器打开。校验、运行、录制场景等子命令会在后续里程碑加入，见路线图。

全部命令

熟悉的人照抄即可，逐步说明在下方
# 1. Git（已经有就跳过）
xcode-select --install

# 2. uv（装完开一个新的终端窗口）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 3. 下载代码
mkdir -p ~/code && cd ~/code
git clone https://github.com/DevopsLeaDevops/web_browser_robotic_process_automation.git
cd web_browser_robotic_process_automation

# 4. 安装依赖与浏览器
uv sync
uv run playwright install chromium

# 5. 确认能运行
uv run rpa --version
uv run pytest

# 6. 打开文档站
open docs/index.html

前置需求

电脑
Apple 芯片（M 系列）或 Intel 的 Mac 都可以。建议使用仍在接收更新的 macOS 版本。
终端
系统内置的「终端」（应用程序 › 实用工具）。默认 shell 是 zsh，本页命令都在 zsh 中运行。
网络
需要连得到 GitHub、PyPI 与 Playwright 的浏览器下载站。公司网络先看常见问题。
磁盘空间
预留约 1 GB，给 Python、包与 Chromium。
不需要
不用自己装 Python、Homebrew 或 Node.js。Python 由 uv 自动下载；Node.js 到 M8 做前端时才需要。

1. 安装 Git

先确认是否已经有 Git：

git --version

印出版本号就跳到下一步。如果跳出要求安装「命令行开发者工具」的窗口，或看到 xcrun: error，运行下面的命令，在弹出的窗口按「安装」并等它完成。不需要安装完整的 Xcode。

xcode-select --install

2. 安装 uv

uv 负责下载 Python、创建虚拟环境和安装包，项目要求 0.11 以上。以下二选一：

官方安装脚本（建议）

curl -LsSf https://astral.sh/uv/install.sh | sh

装在 ~/.local/bin，之后升级用 uv self update。

已经在用 Homebrew

brew install uv

之后升级用 brew upgrade uv。

装完关掉终端，再开一个新窗口让 PATH 生效，然后确认版本：

uv --version    # 例如 uv 0.11.x，需要 0.11 以上

3. 下载代码

放在你习惯的文件夹，这里以家目录下的 code 为例：

mkdir -p ~/code && cd ~/code
git clone https://github.com/DevopsLeaDevops/web_browser_robotic_process_automation.git
cd web_browser_robotic_process_automation
  • 之后所有命令都在这个文件夹里运行。
  • 避开有 iCloud 同步的「桌面」与「文稿」文件夹，.venv 里的大量小文件会被一直同步。
  • 不建议下载 ZIP：没有 Git 记录就无法用 git pull 更新，也无法安装提交前检查。

4. 安装依赖与浏览器

# 依 .python-version 准备 Python 3.13（没有就自动下载），创建 .venv，安装全部包与开发工具
uv sync

# 下载 Playwright 使用的 Chromium
uv run playwright install chromium
.venv/
项目自己的虚拟环境，就在项目文件夹内。不需要手动激活，uv run 会自动使用它。
Python
uv 下载的 Python 放在 ~/.local/share/uv/python，不会动到系统的 Python。
Chromium
放在 ~/Library/Caches/ms-playwright。macOS 不需要加 --with-deps，那是 Linux 用来安装系统函数库的。
uv.lock
第一次 uv sync 会产生锁文件，git status 会看到它。怎么处理见开发环境的常见问题。

5. 确认能运行

命令预期结果
uv run rpa --versionrpa 0.1.0（rpa-core 0.1.0）
uv run rpa -h显示用法与说明「浏览器自动化场景的生成、管理与运行工具。」M0 还没有子命令。
uv run pytest最后一行只有 passed，没有 failed，也没有 skipped。
RPA_REQUIRE_BROWSER=1 uv run pytest -m browser1 passed（其余测试显示为 deselected）。这是浏览器冒烟测试，跟 CI 一样缺浏览器就失败，而不是略过。
如果 uv run pytest 显示 1 skipped、原因是「Chromium 未安装」，代表第 4 步的浏览器没装好，重新运行 uv run playwright install chromium。

rpa 默认以繁体中文显示；要改用简体中文或英文，加上 --lang zh-Hans、--lang en，或设置环境变量 RPA_LANG（例如在 ~/.zshrc 加一行 export RPA_LANG=en）。

不想每次都打 uv run，可以先激活虚拟环境：source .venv/bin/activate，之后直接打 rpa --version、pytest；离开用 deactivate。

6. 打开文档站

# 用默认浏览器直接打开
open docs/index.html

# 或起一个本机服务器，浏览 http://localhost:8000（Control-C 停止）
uv run python -m http.server -d docs 8000

页眉右上角可以切换繁体中文、简体中文与 English。

macOS 没有 python 命令。README 里的 python -m http.server 请改用上面的 uv run python，或系统的 python3。

7. 准备开发

可选
# 每次 git commit 前自动跑 ruff、pyright 与文档检查
uv run pre-commit install
  • 第一次运行 pyright（包含提交时的检查）会自动下载它需要的 Node.js 运行环境，要多等一下。
  • 编辑器的 Python 解释器选项目里的 .venv/bin/python，类型检查才找得到包。
  • 常用命令见开发环境，分支与提交规则见开发规范。

之后每次使用

cd ~/code/web_browser_robotic_process_automation
git pull        # 取得最新代码
uv sync         # 依赖有变动才会安装；没变动几秒内结束
uv run pytest

常见问题

看到什么怎么处理
xcrun: errormacOS 大版本升级后常见，命令行开发者工具需要重装：xcode-select --install。
command not found: uv开一个新的终端窗口。仍不行就运行 source $HOME/.local/bin/env，或用 echo $PATH 确认含有 ~/.local/bin。
command not found: pythonmacOS 默认没有这个命令。用 uv run python（项目的 Python 3.13）或 python3。
uv 版本太旧uv sync 提示需要 0.11 以上时：脚本安装的运行 uv self update，Homebrew 安装的运行 brew upgrade uv。
M 系列芯片却显示 x86_64uname -m 应该印出 arm64。印出 x86_64 代表终端是通过 Rosetta 开的：在 Finder 对「终端」按「显示简介」，取消勾选 Rosetta 那一项，重开终端后运行 rm -rf .venv && uv sync。
Address already in use8000 端口被占用，换一个端口号，例如 uv run python -m http.server -d docs 8001。
git pull 说 uv.lock 会被覆盖锁文件已经提交到 main。删掉本机产生的那份再拉：rm uv.lock && git pull && uv sync。
公司网络、代理或镜像见开发环境的常见问题（UV_INDEX_URL、PLAYWRIGHT_DOWNLOAD_HOST）。
想整个重来重建环境：rm -rf .venv && uv sync。重装浏览器：rm -rf ~/Library/Caches/ms-playwright，再运行 uv run playwright install chromium。
