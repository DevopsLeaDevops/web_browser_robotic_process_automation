必守規則

  • 緊湊資訊密度。不用大橫幅、插畫或大量留白；重複的標題只保留一次。
  • 狀態要有文字。不能只用圖示或色點。
  • 鍵盤可操作。焦點框清楚；對話框可用 Esc 關閉。
  • 三種尺寸驗收。1440×900、1280×720、390×844，不得出現整頁水平捲動。
  • 不另造導覽。新頁面一律放進兩級 Portal。

收錄時發現的缺口
  • 設計變數不完整。tokens.json 沒有成功、警告、錯誤與選取背景色；這些只出現在 portal.css。
  • 選取背景色不一致。設計系統的色彩頁寫 #eaf3ff，portal.css 實際使用 #eaf4ff。
  • 步驟編輯器細節。已有流程畫布與節點樣式，但沒有拖拽、定位器候選切換、校驗錯誤標示的狀態。
  • 執行詳情。逐步日誌、截圖回放與 Trace 連結的版面。
  • YAML 編輯器。已有 code-editor 基礎樣式，需確認語法高亮與錯誤行標示。
  • 圖示。目前只有一個通用圖示，選單與動作需要一套圖示。
  • 深色模式。目前沒有，需確認是否需要。
  • 三種語言的版面。設計包以繁中設計；英文通常較長，原型要用英文與簡中各檢查一次，見 ADR 0007。
