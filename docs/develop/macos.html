macOS 本機運行

在一台沒裝過開發工具的 Mac 上，從下載程式碼到跑通 CLI、測試與文檔站的逐步說明。第一次大約十分鐘，多半在等下載。想一條命令自動做完下面的步驟，用本機從零運行的一鍵腳本。

目前是 M0（工程骨架）。「能運行」指的是：rpa 命令可以執行、全部測試通過、Playwright 能啟動 Chromium、文檔站能在瀏覽器開啟。校驗、執行、錄製場景等子命令會在後續里程碑加入，見路線圖。

全部命令

熟悉的人照抄即可，逐步說明在下方
# 1. Git（已經有就跳過）
xcode-select --install

# 2. uv（裝完開一個新的終端機視窗）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 3. 下載程式碼
mkdir -p ~/code && cd ~/code
git clone https://github.com/DevopsLeaDevops/web_browser_robotic_process_automation.git
cd web_browser_robotic_process_automation

# 4. 安裝依賴與瀏覽器
uv sync
uv run playwright install chromium

# 5. 確認能運行
uv run rpa --version
uv run pytest

# 6. 開啟文檔站
open docs/index.html

前置需求

電腦
Apple 晶片（M 系列）或 Intel 的 Mac 都可以。建議使用仍在接收更新的 macOS 版本。
終端機
系統內建的「終端機」（應用程式 › 工具程式）。預設 shell 是 zsh，本頁命令都在 zsh 中執行。
網路
需要連得到 GitHub、PyPI 與 Playwright 的瀏覽器下載站。公司網路先看常見問題。
磁碟空間
預留約 1 GB，給 Python、套件與 Chromium。
不需要
不用自己裝 Python、Homebrew 或 Node.js。Python 由 uv 自動下載；Node.js 到 M8 做前端時才需要。

1. 安裝 Git

先確認是否已經有 Git：

git --version

印出版本號就跳到下一步。如果跳出要求安裝「命令列開發者工具」的視窗，或看到 xcrun: error，執行下面的命令，在彈出的視窗按「安裝」並等它完成。不需要安裝完整的 Xcode。

xcode-select --install

2. 安裝 uv

uv 負責下載 Python、建立虛擬環境和安裝套件，專案要求 0.11 以上。以下二選一：

官方安裝腳本（建議）

curl -LsSf https://astral.sh/uv/install.sh | sh

裝在 ~/.local/bin，之後升級用 uv self update。

已經在用 Homebrew

brew install uv

之後升級用 brew upgrade uv。

裝完關掉終端機，再開一個新視窗讓 PATH 生效，然後確認版本：

uv --version    # 例如 uv 0.11.x，需要 0.11 以上

3. 下載程式碼

放在你習慣的資料夾，這裡以家目錄下的 code 為例：

mkdir -p ~/code && cd ~/code
git clone https://github.com/DevopsLeaDevops/web_browser_robotic_process_automation.git
cd web_browser_robotic_process_automation
  • 之後所有命令都在這個資料夾裡執行。
  • 避開有 iCloud 同步的「桌面」與「文件」資料夾，.venv 裡的大量小檔案會被一直同步。
  • 不建議下載 ZIP：沒有 Git 紀錄就無法用 git pull 更新，也無法安裝提交前檢查。

4. 安裝依賴與瀏覽器

# 依 .python-version 準備 Python 3.13（沒有就自動下載），建立 .venv，安裝全部套件與開發工具
uv sync

# 下載 Playwright 使用的 Chromium
uv run playwright install chromium
.venv/
專案自己的虛擬環境，就在專案資料夾內。不需要手動啟用，uv run 會自動使用它。
Python
uv 下載的 Python 放在 ~/.local/share/uv/python，不會動到系統的 Python。
Chromium
放在 ~/Library/Caches/ms-playwright。macOS 不需要加 --with-deps，那是 Linux 用來安裝系統函式庫的。
uv.lock
倉庫裡的鎖檔，記錄每個套件的確切版本；uv sync 依它安裝，所以每個人裝到的版本相同。

5. 確認能運行

命令預期結果
uv run rpa --versionrpa 0.1.0（rpa-core 0.1.0）
uv run rpa -h顯示用法與說明「瀏覽器自動化場景的生成、管理與執行工具。」M0 還沒有子命令。
uv run pytest最後一行只有 passed，沒有 failed，也沒有 skipped。
RPA_REQUIRE_BROWSER=1 uv run pytest -m browser1 passed（其餘測試顯示為 deselected）。這是瀏覽器冒煙測試，跟 CI 一樣缺瀏覽器就失敗，而不是略過。
如果 uv run pytest 顯示 1 skipped、原因是「Chromium 未安裝」，代表第 4 步的瀏覽器沒裝好，重新執行 uv run playwright install chromium。

rpa 預設以繁體中文顯示；要改用簡體中文或英文，加上 --lang zh-Hans、--lang en，或設定環境變數 RPA_LANG（例如在 ~/.zshrc 加一行 export RPA_LANG=en）。

不想每次都打 uv run，可以先啟用虛擬環境：source .venv/bin/activate，之後直接打 rpa --version、pytest；離開用 deactivate。

6. 開啟文檔站

# 用預設瀏覽器直接開啟
open docs/index.html

# 或起一個本機伺服器，瀏覽 http://localhost:8000（Control-C 停止）
uv run python -m http.server -d docs 8000

頁首右上角可以切換繁體中文、简体中文與 English。

macOS 沒有 python 命令。README 裡的 python -m http.server 請改用上面的 uv run python，或系統的 python3。

7. 準備開發

可選
# 每次 git commit 前自動跑 ruff、pyright 與文檔檢查
uv run pre-commit install
  • 第一次執行 pyright（包含提交時的檢查）會自動下載它需要的 Node.js 執行環境，要多等一下。
  • 編輯器的 Python 直譯器選專案裡的 .venv/bin/python，型別檢查才找得到套件。
  • 常用命令見開發環境，分支與提交規則見開發規範。

之後每次使用

cd ~/code/web_browser_robotic_process_automation
git pull        # 取得最新程式碼
uv sync         # 依賴有變動才會安裝；沒變動幾秒內結束
uv run pytest

常見問題

看到什麼怎麼處理
xcrun: errormacOS 大版本升級後常見，命令列開發者工具需要重裝：xcode-select --install。
command not found: uv開一個新的終端機視窗。仍不行就執行 source $HOME/.local/bin/env，或用 echo $PATH 確認含有 ~/.local/bin。
command not found: pythonmacOS 預設沒有這個命令。用 uv run python（專案的 Python 3.13）或 python3。
uv 版本太舊uv sync 提示需要 0.11 以上時：腳本安裝的執行 uv self update，Homebrew 安裝的執行 brew upgrade uv。
M 系列晶片卻顯示 x86_64uname -m 應該印出 arm64。印出 x86_64 代表終端機是透過 Rosetta 開的：在 Finder 對「終端機」按「取得資訊」，取消勾選 Rosetta 那一項，重開終端機後執行 rm -rf .venv && uv sync。
Address already in use8000 埠被佔用，換一個埠號，例如 uv run python -m http.server -d docs 8001。
git pull 說 uv.lock 會被覆蓋鎖檔已經提交到 main。刪掉本機產生的那份再拉：rm uv.lock && git pull && uv sync。
公司網路、代理或鏡像見開發環境的常見問題（UV_INDEX_URL、PLAYWRIGHT_DOWNLOAD_HOST）。
想整個重來重建環境：rm -rf .venv && uv sync。重裝瀏覽器：rm -rf ~/Library/Caches/ms-playwright，再執行 uv run playwright install chromium。
