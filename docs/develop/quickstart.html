本機從零運行

一條命令，從一台沒裝過開發工具的電腦，到 CLI、測試與文檔站都跑通。macOS、Linux、Windows 都適用；第一次大約十分鐘，多半在等下載。

目前是 M0（工程骨架）。「能運行」指的是：rpa 命令可以執行、全部測試通過、Playwright 能啟動 Chromium、文檔站能在瀏覽器開啟。校驗、執行、錄製場景等子命令會在後續里程碑加入，見路線圖。

macOS、Linux

在「終端機」執行
# 還沒下載程式碼：下載到 ~/code/web_browser_robotic_process_automation 並安裝
curl -LsSf https://raw.githubusercontent.com/DevopsLeaDevops/web_browser_robotic_process_automation/main/scripts/setup.sh | bash

# 已經 clone 了：在專案資料夾裡執行
./scripts/setup.sh

Windows

在 PowerShell 執行
# 還沒下載程式碼：先下載腳本，再執行；程式碼會下載到 %USERPROFILE%\code\web_browser_robotic_process_automation
irm https://raw.githubusercontent.com/DevopsLeaDevops/web_browser_robotic_process_automation/main/scripts/setup.ps1 -OutFile $env:TEMP\rpa-setup.ps1
powershell -ExecutionPolicy Bypass -File $env:TEMP\rpa-setup.ps1

# 已經 clone 了：在專案資料夾裡執行
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1

執行前要有什麼

macOS
什麼都不用先裝。沒有 Git 時，腳本會叫出「命令列開發者工具」的安裝視窗，裝完再執行一次同一條命令。
Linux
需要 Git，以及 curl 或 wget。Chromium 缺系統函式庫時，腳本會用 sudo 自動安裝（限 Debian、Ubuntu）。
Windows
Windows 10 以上，內建的 PowerShell 5.1 即可。沒有 Git 時，腳本會用 winget 安裝。
網路
需要連得到 GitHub、astral.sh（uv）、PyPI 與 Playwright 的瀏覽器下載站。公司網路見常見問題。
磁碟空間
預留約 1 GB，給 Python、套件與 Chromium。
不需要
Python、Homebrew、Node.js 都不用自己裝。Python 由 uv 下載，不會動到系統的 Python。

執行前想先看腳本

  • 腳本在倉庫的 scripts/setup.sh 與 scripts/setup.ps1，開頭有完整說明。
  • 習慣先看再跑：把命令裡的網址貼到瀏覽器打開，或先 git clone 再執行專案裡的那一份。Windows 的命令本來就是先下載成檔案，可以打開看過再執行第二行。
  • 腳本只會在你的家目錄安裝 uv 與 Python、在專案資料夾建立 .venv、下載 Chromium；需要系統權限的只有安裝 Git（macOS、Windows）與 Linux 的瀏覽器函式庫，都會先詢問。
  • 重複執行是安全的：已經完成的步驟會很快跳過，所以失敗後修正問題，重跑同一條命令即可。

腳本做了什麼

兩個平台的步驟相同
步驟做什麼已經完成時
1. 檢查系統確認作業系統與 CPU 架構。Apple 晶片的 Mac 在 Rosetta 下執行時會提醒。每次都檢查
2. 準備程式碼在專案裡執行就用這一份；否則用 git clone 下載到預設位置或 --dir 指定的位置。已經下載過就直接使用，不會自動 git pull
3. 準備 uv沒有就用官方安裝腳本安裝；版本低於 pyproject.toml 的 required-version 時嘗試升級。版本夠新就跳過
4. 安裝 Python 與依賴uv sync：依 .python-version 準備 Python 3.13，建立 .venv，安裝全部套件與開發工具。沒有變動時幾秒內結束
5. 安裝 Chromiumuv run playwright install chromium，再實際啟動一次。Linux 缺系統函式庫時執行 playwright install-deps。已下載就跳過下載，只做啟動檢查
6. 安裝提交前檢查uv run pre-commit install，之後每次 git commit 前自動跑 ruff、pyright 與文檔檢查。重新寫入同一個 hook，不影響
7. 確認能運行執行 rpa --version，再設定 RPA_REQUIRE_BROWSER=1 跑全部測試：跟 CI 一樣，缺瀏覽器直接失敗而不是略過。每次都跑

選項

macOS、LinuxWindows作用
--dir <路徑>-Dir <路徑>還沒有程式碼時下載到哪裡。也可以用環境變數 RPA_DIR。在專案資料夾裡執行時沒有作用。
--skip-browser-SkipBrowser不下載 Chromium，需要瀏覽器的測試會略過。連不到瀏覽器下載站時，先用它把其他部分跑通。
--skip-tests-SkipTests只安裝，不跑測試。
--no-hooks-NoHooks不安裝提交前檢查。
--helpGet-Help .\scripts\setup.ps1 -Detailed顯示說明。

從零開始的命令也可以帶選項：

# macOS、Linux：選項放在 bash -s -- 後面
curl -LsSf https://raw.githubusercontent.com/DevopsLeaDevops/web_browser_robotic_process_automation/main/scripts/setup.sh | bash -s -- --skip-browser

# Windows：選項放在 -File 腳本路徑後面
powershell -ExecutionPolicy Bypass -File $env:TEMP\rpa-setup.ps1 -SkipBrowser

成功的樣子

最後一步印出版本、全部測試只有 passed，接著是「完成」與接下來可以用的命令：

[7/7] 確認能運行
  ✓ rpa 0.1.0（rpa-core 0.1.0）
  $ env RPA_REQUIRE_BROWSER=1 uv run pytest
…
============================= 46 passed in 2.91s ==============================
  ✓ 全部測試通過

完成！本機環境已經可以運行。

接下來在專案資料夾裡：
  cd /Users/you/code/web_browser_robotic_process_automation
  uv run rpa -h                               # 命令列工具
  uv run pytest                               # 跑測試
  open docs/index.html                        # 開啟文檔站
  uv run python -m http.server -d docs 8000   # 或用本機伺服器瀏覽文檔
  • 測試數量會隨著程式碼與文檔頁面增加，重點是沒有 failed、也沒有 skipped。
  • 中途失敗時，腳本會用 ✗（Windows 是 [X]）標出停在哪一步，以及怎麼處理。
  • 以 !（Windows 是 [!]）開頭的是提醒，不影響運行，但建議看一下。

之後每次使用

cd ~/code/web_browser_robotic_process_automation
git pull              # 取得最新程式碼
./scripts/setup.sh    # 依賴、瀏覽器有變動才會安裝，最後重跑測試；Windows 用 scripts\setup.ps1

只想更新依賴、不想跑完整流程時，用 uv sync 即可。其他常用命令見開發環境。

常見問題

看到什麼怎麼處理
Windows：「因為這個系統上已停用指令碼執行」用本頁帶 -ExecutionPolicy Bypass 的命令執行，只對這一次有效，不需要改系統設定。
Windows：用 irm … | iex 執行，出現「is not recognized」或「Unexpected attribute」改用本頁「先下載、再用 -File 執行」的兩行命令。腳本存成含 BOM 的 UTF-8，Windows PowerShell 5.1 才不會把中文讀成亂碼；但 BOM 會留在 irm 下載的字串裡，讓 iex 解析失敗。
macOS：「請在跳出的視窗按『安裝』」安裝命令列開發者工具，完成後再執行同一條命令。不需要安裝完整的 Xcode。
「已經存在，而且不是空資料夾」預設位置被其他東西佔用。用 --dir（Windows 是 -Dir）指定別的位置；如果那就是專案，進到資料夾裡執行 scripts/setup.sh。
「安裝依賴失敗」或「下載 Chromium 失敗」多半是公司網路。設定 UV_INDEX_URL 或 PLAYWRIGHT_DOWNLOAD_HOST 後重跑，見開發環境的常見問題；瀏覽器暫時下載不了，可以先加 --skip-browser。
Linux：「Chromium 缺少系統函式庫」腳本會用 sudo 執行 playwright install-deps，需要輸入密碼。不是 Debian、Ubuntu 時，依錯誤訊息手動安裝缺少的函式庫。
完成後輸入 uv 顯示找不到命令腳本剛安裝 uv，只對新開的終端機視窗生效。開一個新視窗；macOS、Linux 也可以執行 source $HOME/.local/bin/env。
「測試沒有通過」往上找 FAILED 的測試名稱與錯誤。在專案資料夾執行 uv run pytest -x 可以停在第一個失敗。
想整個重來刪除專案裡的 .venv，再執行一次腳本。Mac 特有的問題（Rosetta、xcrun: error 等）見 macOS 本機運行的常見問題。
不想用腳本、或想知道每一步的細節：Mac 的逐步說明見 macOS 本機運行，各平台通用的命令見開發環境。
