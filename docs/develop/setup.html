開發環境

從零到能跑測試，大約五分鐘。Windows、macOS、Linux 指令相同。想一條命令裝好全部，用本機從零運行的一鍵腳本；第一次在 Mac 上設定，可照macOS 本機運行一步步做。

第一次設定

git clone https://github.com/DevopsLeaDevops/web_browser_robotic_process_automation.git
cd web_browser_robotic_process_automation

# 建立 .venv，安裝全部套件與開發工具
uv sync

# 下載 Chromium（Linux 第一次可加 --with-deps 安裝系統依賴）
uv run playwright install chromium

# 提交前自動檢查
uv run pre-commit install

# 確認安裝成功
uv run rpa --version

3.12 以上。沒有的話 uv 會自動下載。

Git

常用命令

做什麼命令
安裝或檢查整個環境./scripts/setup.sh（Windows：scripts\setup.ps1），見本機從零運行
跑全部測試uv run pytest
跳過需要瀏覽器的測試uv run pytest -m "not browser"
只檢查文檔uv run pytest tests/docs
Lint 並自動修正uv run ruff check --fix .
格式化uv run ruff format .
型別檢查uv run pyright
提交前的全部檢查uv run pre-commit run --all-files
替某個套件加依賴uv add --package rpa-core 套件名稱
以其他語言顯示 rpauv run rpa --lang en -h，或設定環境變數 RPA_LANG=zh-Hans
重新產生簡中、檢查翻譯uv run python tools/i18n.py sync、uv run python tools/i18n.py check，見三種語言
瀏覽文檔直接開啟 docs/index.html，或 python -m http.server -d docs 8000

常見問題

沒有 uv.lock
M0 尚未提交鎖檔。第一位執行 uv sync 的成員會產生 uv.lock，請單獨開一個 PR 提交；之後 CI 會自動改用 uv sync --locked。
內網連不到 PyPI
設定環境變數 UV_INDEX_URL 指向公司的套件鏡像。
瀏覽器下載失敗
設定 PLAYWRIGHT_DOWNLOAD_HOST 指向內部鏡像；瀏覽器冒煙測試在本機沒有瀏覽器時會自動略過。
測試說簡中不是最新
改了繁中文檔或訊息目錄後，執行 uv run python tools/i18n.py sync 並提交產生的檔案。
測試說英文翻譯需要更新
依繁中的修改更新 docs/en/ 的同一頁，再執行測試訊息裡的 stamp 命令。
pyright 找不到套件
確認已執行 uv sync，且編輯器使用的是專案的 .venv。
