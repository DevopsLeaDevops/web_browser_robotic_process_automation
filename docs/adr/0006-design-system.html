ADR 0006：採用介面設計系統 v1.0 作為視覺契約

同事交付的設計包原樣收錄，文檔站與未來的 Web UI 共用。

已接受
日期
2026-10-09
影響範圍
docs/、M6 頁面原型、M8 Web UI
相關
風格總覽、ADR 0004

背景

路線圖的 M6 是網站風格設計。同事已交付一版介面設計系統 v1.0：設計變數、共用樣式、兩級選單外殼與起始版型，並在三種螢幕尺寸驗證過。

決策

  • 設計包原樣收錄在 docs/design-system/，不直接修改；MANIFEST.json 的 sha256 由測試檢查。
  • 文檔站從 M0 起使用它的 portal.css。
  • M6 以 starter.html 為基礎製作本工程的頁面原型。
  • M8 把 portal.css 與 tokens.json 移植到 React 前端。
  • 設計包更新時整包替換，並在本頁記錄版本。

後果

好處

  • 文檔與產品風格一致；M6 從「設計風格」縮小為「設計頁面」。
  • 設計包已包含流程編輯器相關樣式（流程畫布、節點、元件庫），可直接用於步驟編輯器。

代價

  • 本工程需要但設計包尚未涵蓋的部分，要在 M6 與設計者確認，見風格總覽。
  • 不能直接改設計包；本工程的補充樣式寫在自己的檔案裡。

沒有選的方案

方案為什麼不選
重新設計重複工作，且已有驗證過的成果。
採用現成元件庫需要另外調整成團隊風格，與設計包重疊。
