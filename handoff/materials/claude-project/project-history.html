專案一句話

內網用的瀏覽器 RPA 平台：場景以聲明式 YAML DSL 描述（必要時用 Python 腳本當逃生門），有入參、出參與獨立斷言；在管理 Portal 錄製、調試、驗證、發布、執行並查看報告；以 Playwright 在 Chromium 與 Firefox 執行。先交付單機、單使用者的 MVP（M5 完成時），再擴充流程能力、多用戶與營運。

倉庫：DevopsLeaDevops/web_browser_robotic_process_automation；技術：Python 3.12+、uv workspace、FastAPI + Jinja、SQLAlchemy + Alembic（SQLite，之後 PostgreSQL）、Playwright。文檔：docs/，HTML，三種語言。
