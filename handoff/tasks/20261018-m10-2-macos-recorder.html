進度、決定與下一步

  • 計畫（使用者核准，2026-10-18 08:59 America/Los_Angeles（PDT，UTC−07:00））：
    • 子程序交給哪台跑：三個服務（錄製、逐步調試、人工登入）啟動子程序的地方改成可以交給錄製端；伺服器送出「模組＋參數＋需要的檔案」，錄製端在自己的暫存資料夾重建檔案再執行。錄製稿轉 DSL、遮罩密碼、建草稿、存登入狀態全部仍在伺服器。
    • 檔案回傳：錄製端每送一行輸出之前，先把這段時間新增或改過的檔案傳回；結束時再同步一次並回報結束碼。
    • 失聯：超過 30 秒沒消息，伺服器把它的子程序視為結束（調試中斷、錄製失敗）。
    • 錄製端用獨立的資料表（遷移 0009），Worker 的領取邏輯不動；邀請沿用 device_invites。
    • 閘道：權杖只在錄製端的本機閘道，網頁拿不到；閘道每次啟動產生密語，同一台電腦上的其他程式用不了。
    • 測試網站：錄製端也在 127.0.0.1:8765 啟動測試網站。
    • 關掉視窗就結束 App（不做選單列圖示）；有錄製或調試在進行時先確認。
    • 端到端 CI 測逐步調試（無頭）；錄製與人工登入要人操作，靠人工驗收。
  • 決定（2026-10-18 08:59 America/Los_Angeles（PDT，UTC−07:00））：使用者回覆「ok, PR1 and PR2 start together」，核准計畫並要 PR 1、PR 2 一起開始。三個待決定事項沒有逐一回答，照計畫裡的預設進行（使用者可以再改）：(1) 先用伺服器那台 Mac 配對 127.0.0.1:8081 測整條路，有第二台 Mac 時再測「瀏覽器開在別台」；(2) 只做 Apple 晶片、不簽章（第一次開啟要到「系統設定 › 隱私權與安全性」允許）；(3) 錄製端的權杖能看、改所有東西（和本機 8080 一樣），M8 才有使用者權限，信任的區網內接受。
  • PR 1 的內容（實作完成，2026-10-18 10:00 America/Los_Angeles（PDT，UTC−07:00））：
    • 錄製端裝置：遷移 0009 新增 recorders 資料表與 recordings.device_id；裝置頁新增時可以選「RPA 錄製端」，有自己的清單（狀態：線上、忙碌、離線、停用）、停用、重新邀請、刪除；邀請沿用 device_invites（app="recorder"），邀請的命令是 uv run rpa recorder --invite …；API /api/recorders。
    • 對外埠的 Portal：PortGateMiddleware 在對外埠上，Worker API 與配對以外的路徑只接受錄製端的權杖（worker 的權杖也是 401），認出後把裝置放進這個請求的 context（rpa_server.context）。頁首顯示「透過錄製端「名稱」」；執行位置的「本機」顯示成「伺服器」（page_t 換訊息鍵）。
    • Client API：POST /hello（開機代號換了就把舊的子程序視為結束）、POST /control（長輪詢 25 秒，以序號確認）、PUT /processes/<id>/files（zip）、POST /processes/<id>/output（幾行、結束碼、啟動失敗的原因）。
    • 子程序交給錄製端：RecorderHub.launcher(裝置)（rpa_server.devices）傳回和 Popen 用法相同的 RemoteProcess；錄製、逐步調試、人工登入三個服務依請求來自哪台選 launcher，啟動前檢查那台在線、有畫面（有頭時）、有那個瀏覽器。參數裡的工作目錄換成 {work}，工作目錄外的輸入檔放進 .inputs/；只送服務明確指定的環境變數。失聯（30 秒）、重新啟動、停用、刪除、重新邀請、伺服器停止時子程序以結束碼 -1001 結束，原因寫進日誌，並送出結束指令。
    • 錄製端程式（apps/worker，App 與命令列共用）：rpa_worker.recorder.RecorderHost（上線、輪詢、在暫存資料夾執行子程序、每行輸出前先傳回改過的檔案、結束後刪掉暫存資料夾、404 時結束子程序、權杖被拒時停止）；rpa_worker.gateway.Gateway（127.0.0.1 的本機閘道：每次啟動的密語 Cookie、加上權杖轉送、改寫 Origin 與 Location、擋外來 Origin 與 DNS rebinding、/__desktop/ 的本機頁面、離線頁、401 回呼）；rpa_worker.interactive（共用的常數、安全路徑、打包與解開檔案）。
    • 命令列：rpa recorder（--invite、--server、--name、--work-dir recorder-data、--port、--open/--no-open、--testsite/--no-testsite）：權杖只能用邀請換（不收環境變數或權杖檔）；開閘道、用預設瀏覽器打開；Ctrl+C 停止。
