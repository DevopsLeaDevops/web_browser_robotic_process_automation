工作區／環境
Claude 雲端容器 Linux x86_64、Python 3.13.17。PyPI 被代理拒絕（uv sync --locked 失敗，files.pythonhosted.org 的 CONNECT 回 403），改用系統 Python 加上依 uv.lock 版本從 GitHub clone 的 fastapi 0.148.0、starlette 1.9.0、sqlalchemy 2.1.5、alembic 1.20.0、mako 1.4.3、annotated-doc 0.0.5；Ruff 0.17.1（GitHub release）、Pyright 1.1.414、pytest 9.1.1（沒有 pytest-xdist）；系統 Playwright 只有 Chromium（chromium-1243），沒有 Firefox。簡中靠 [bootstrap]。

原因

  1. DebugManager.reload 把新版本的場景檔與入參寫進伺服器上這個工作階段的資料夾，再送 {"cmd": "load", "scenario": 伺服器路徑, "input": 伺服器路徑}。
  2. 工作階段在錄製端時，命令經 RemoteProcess 的標準輸入原樣送出（devices.py 的 _Stdin.write）；路徑轉換與傳檔（_Translator）只在開始調試時做。
  3. 錄製端把這一行原樣寫給子程序；子程序讀不到伺服器的路徑，validate_file 回「檔案讀不到」，_load 只拋出「場景校驗失敗」，伺服器轉成 422 revision_invalid。
  4. CI 沒抓到：test_recorder_flow.py 的錄製端和伺服器在同一台、同一個磁碟，伺服器的路徑剛好讀得到。M10.2（錄製端，2026-10-19）起所有「伺服器沒有瀏覽器、調試在錄製端」的部署都會遇到。
