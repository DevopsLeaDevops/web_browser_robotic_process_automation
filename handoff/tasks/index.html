共同開發任務索引

每個實作任務一份 HTML 紀錄；主責、進度與證據只在該紀錄維護。索引只列連結，避免兩邊重複維護狀態。

本分支的索引不是全域鎖。未合併任務可能只存在於其他分支或 PR；開工前必須核對使用者分工與 GitHub 活躍 PR。同一分支只允許一位當前實作者。

任務紀錄

  • 20261014-dag-composite-scenes：DAG 畫布與組合場景自動化
  • 20261014-shared-ai-workflow：建立 Claude 與 ChatGPT 共用協作流程

維護方式

  1. 複製同目錄的 _template.html，以日期和主題命名並在此加連結；路徑保持相對於 handoff/tasks/。
  2. 任務自己的紀錄隨分支一同提交，主責變更、驗證、交出與接收都記在該檔。純問答和查詢不建卡。
  3. 整合索引衝突時保留所有不同任務的連結；同一任務由一位整合者確認，不用整檔覆蓋。
  4. 已完成的任務保留連結及追加紀錄；業務里程碑另更新 狀態總表與驗收紀錄。
