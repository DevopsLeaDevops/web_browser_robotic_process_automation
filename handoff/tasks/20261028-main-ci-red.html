原因

  • 有頭錄影測試沒有螢幕（環境，v0.6.3 之前就有）。main 推送時 Python 3.12 跑全部測試，packages/rpa_runner/tests/test_video_browser.py::test_chromium_keeps_popup_and_return_to_main[headed-*] 用有頭的 Chromium，CI 沒有 xvfb-run：「Missing X server or $DISPLAY」。84b4611（v0.6.3 之前）、56936f6、56953fc、a26b929 都是這兩項。每晚完整測試在 Linux 用 xvfb-run -a，所以通過。
  • 驗證通過後馬上發布（產品的競態）。RunQueue.complete（jobs.py）先提交「通過」，之後才由 on_finished → run_finished → packs.record_run 把驗證紀錄寫進領域資料夾並標記版本 verified。這段空檔裡打開運行頁看不到「發布」（can_publish 看 verified），執行結束後頁面不再自動重新整理，所以一直看不到；直接呼叫發布則回 409 not_validated。a26b929 的 test_portal.py::test_create_validate_publish_run_report[None-chromium] 等不到發布按鈕而逾時；每晚測試 10-27 的 macOS（Firefox）同一項、10-23、10-25 Windows 的 test_playground_chains_published_scenarios 與 test_remote_worker_runs_validation_and_playground 回 409（分析見 20261026-scheduled-update-tests 的「第三個原因」）。
